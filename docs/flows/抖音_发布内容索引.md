# 抖音文章发布索引（网页版）

## 目的
- 给执行器一个稳定的“入口优先级 + 失败恢复”索引，避免在抖音首页反复无效点击。
- 用于抖音通用发布内容任务，支持发布前校验与发布成功确认。

## 入口优先级索引（按顺序尝试）
1. 顶部导航中的“投稿/创作者服务中心/创作中心”入口。
2. 个人中心中的“创作中心/发布管理”入口。
3. 直接 URL 收敛到创作者域名（仅在确认偏航或入口不可交互时使用地址栏恢复）。

## 页面证据判定
- 进入创作者域成功证据（满足任一）：
  - URL 包含 `creator`、`publish`、`studio` 等创作语义片段；
  - 页面出现“创作中心/发布/图文/标题/正文”等字段或菜单。
- 进入编辑器成功证据（满足至少两项）：
  - 标题输入；
  - 正文输入；
  - 话题/标签；
  - 发布按钮。

## 失败恢复（按动作类型分流）
- 点击未生效：
  1. `Esc` 关闭弹层；
  2. 改点同控件不同区域或双击；
  3. 必要时 `Tab + Enter`。
- 输入未生效：
  1. 单击输入框本体；
  2. `Ctrl + A` 后重输。
- 仅当确认导航偏航时再使用：
  - `Ctrl + L` -> 输入目标 URL -> `Enter`。

## 常见误操作拦截
- 禁止点击浏览器壳层控件（Edge 账号头像、右上角“三点菜单”）作为站内入口。
- 若误打开浏览器菜单，优先 `Esc` 关闭后回到页面再操作。
