# 小红书纯文本笔记发布详细操作指引

目标：在小红书创作服务平台完成“纯文本笔记”发布，避免误点导致流程重开。

## A. 入口与目标模式

1. 打开 `https://creator.xiaohongshu.com/publish`。
2. 若在“上传视频/上传图文”页，切换到“写长文”。
3. 点击“新的创作”进入长文编辑器。

成功标志：

- 页面出现“输入标题”与“粘贴到这里或输入文字”。

## B. 标题与正文输入顺序

1. 先输入标题，再输入正文。
2. 标题建议先完成后不再改动，避免后续“一键排版”提示“请输入标题”。
3. 正文输入前先确认编辑焦点在正文区。

成功标志：

- 标题计数由 `0/64` 变为非 0。
- 正文区域出现实际文本内容。

## C. 正文焦点确认（必须）

若点击正文区后无明显变化，执行“插入字符主动探测 + 回滚”：

1. 在目标输入区插入探测字符（如 `0`）。
2. 立即回滚（优先 `Ctrl+Z`，否则 `Backspace`）。
3. 校验回滚后内容与插入前一致，再正式输入正文。

失败处理：

- 若探测失败，不重复同一点点击。
- 执行恢复动作：`Esc` -> 重新定位输入区 -> 再探测一次。

## D. 提交流程（编辑器内闭环）

1. 在编辑器内点击“一键排版”。
2. 进入预览/下一步页面后继续完成发布。
3. 按页面要求完成必要设置后点击最终发布。

禁止动作：

- 在长文编辑器内点击左侧“发布笔记”入口按钮（会返回入口页并中断当前编辑流程）。

## E. 动作确认门（每步都要检查）

动作后必须满足其一再继续：

- URL 变化；
- 画面差异超过阈值；
- 目标元素状态变化（按钮消失、新区域出现、文案变化）。

若都不满足：

1. 禁止重复原动作；
2. 转恢复动作：`Esc` -> `Ctrl+L` -> 输入目标 URL 回车，或重新定位可编辑输入框后 `Ctrl+A + 粘贴`。

## F. 常见异常恢复

1. 提示“请输入标题”：
   - 回到标题输入框补全标题，再重新执行“一键排版”。
2. 页面误回“上传视频/上传图文/写长文”入口：
   - 判定流程已偏航，重新进入“写长文”并恢复编辑器状态。
3. 下方按钮不可见：
   - 先恢复窗口（如 `Win+Up`），确认浏览器缩放 100%。

## G. 完成判定

满足以下条件即可判定任务完成：

1. 标题、正文均已存在；
2. 已通过编辑器内“一键排版 -> 下一步/发布”路径；
3. 页面出现发布成功或发布后状态确认信息。
