# 小红书养号流程（互动优先版）

目标：执行连续养号任务，核心是“自然浏览与互动”，发布只作为低频动作，避免连续发布。

## A. 任务总原则

1. 每轮先做互动动作，再判断是否允许发布。
2. 不允许把“发布”当作每轮默认动作。
3. 若已发布成功，本轮后续动作必须回到浏览/互动，不得再次发布。
4. 任何一步触发动作确认门，先走恢复链路再继续。

## B. 单轮动作优先级

1. 浏览推荐流或搜索话题（停留、翻页、进入详情）。
2. 点赞/收藏（分散到不同内容与作者）。
3. 评论（短评、自然语气，不复制粘贴固定模板）。
4. 关注（少量、与主题相关）。
5. 仅在策略允许时执行发布。

成功标志：

- 页面出现推荐内容、详情页、话题页等可浏览区域；
- 至少完成 2 种互动动作（点赞/收藏/评论/关注）。

## C. 发布策略门控（必须）

1. 发布频率：每 N 轮最多 1 次（由系统参数控制）。
2. 冷却时间：距离上一次发布需超过冷却阈值。
3. 会话上限：单次任务运行期间发布次数不超过上限。
4. 任一条件不满足：本轮禁止发布，只做互动。

## D. 允许发布时的流程

1. 进入发布入口并切到“写长文”。
2. 输入标题与正文（发布前必须检查均非空）。
3. 按编辑器内路径完成“一键排版 -> 下一步 -> 发布”。
4. 出现“发布成功”后，本轮立即回到互动动作。

禁止动作：

- 在不允许发布的轮次执行“一键排版/下一步/发布”。
- 发布成功后立即再次进入发布流程。

## E. 恢复与安全

动作后必须满足其一再继续：

- URL 变化；
- 画面差异变化明显；
- 目标元素状态变化。

若都不满足：

1. 禁止重复同一点点击；
2. 执行恢复链路：`Esc` -> `Ctrl+L` -> 输入目标 URL 回车，或重新聚焦目标输入框。

## F. 完成判定

以下任一成立可结束本轮：

1. 已完成本轮互动目标（至少 2 种互动动作）；
2. 本轮允许发布且已发布成功，随后完成至少 1 个互动动作。

注意：养号为持续任务，结束“某一轮”不等于结束“整个会话”，除非达到轮次上限或手动停止。
