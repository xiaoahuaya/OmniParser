# 小红书长文纯文本发布流程

> 目标：在 Windows VM 的 Edge 浏览器里，把“今日项目进度”类纯文本内容发布为小红书长文笔记，避免误回入口或提交空字段。

## 1. 入口确认

1. 访问 `https://creator.xiaohongshu.com/publish`。
2. 识别导航卡片：
   - 上传视频
   - 上传图文
   - **写长文**（需要点击）
3. 若看到“新的创作”按钮或标题输入框，说明已进入长文编辑器，可继续下一节。

## 2. 编辑器步骤清单

| 步骤 | 操作 | 成功标志 |
| --- | --- | --- |
| 1 | 点击“新的创作” | 编辑器出现标题 `输入标题/0-64` |
| 2 | 点击标题输入框，一次即可 | 右上角显示 `0/64` 计数 |
| 3 | 输入标题（例如 `本项目｜今日进度总结（3/5）`） | 计数更新为 `7/64` 等 |
| 4 | 点击正文区域“粘贴到这里或输入文字” | 占位符高亮或消失 |
| 5 | 粘贴/输入正文（包含今日完成、进行中、风险、下一步） | 正文出现文本且字数统计增长 |
| 6 | 可选：添加标签（`#项目进度 #今日总结` 等） | 标签列表更新 |

## 3. 发布前校验

- **标题检查**：若页面出现 “请输入标题” 提示，必须回到标题框重填。
- **正文检查**：确保正文不为空、字数>0。
- **页面状态**：确认仍在编辑器（左上角有“新的创作”，右下角有“一键排版”）。

## 4. 正确的发布路径

1. 点击“一键排版” → 预览页。
2. 如提示“请输入标题”，返回步骤 3 重新填写。
3. 在预览页点击“下一步/发布”。
4. 填写发布设置（如分类、可见范围），点击最终“发布”。

## 5. 风险与恢复

- **误点“发布笔记”返回入口页**：
  - 立即 `Alt+Left` 或重新访问 `https://creator.xiaohongshu.com/publish/publish?...`。
  - 再次点击“写长文” → “新的创作”。
- **动作确认门触发**：
  - 遵循提示：Esc → Ctrl+L → 输入目标 URL → 回车。
  - 再次进入写长文编辑器。
- **焦点丢失**：
  - 单击目标输入框一次，等待 0.3s，再执行输入。

## 6. 执行提示

- 在“发布”之前不要点击入口页的“发布笔记”。
- 任意离开编辑器动作都应在检查清单通过后执行。
- 如果后续要复用本流程，可将本文件作为代理提示或系统提示的一部分。
