# 小红书发布流程插座（通用）

目标：当任务意图识别为“小红书发布”时，优先按本流程执行，减少误点、循环点击、回到入口页重开流程等问题。

## 1. 进入与模式确认

1. 打开小红书创作入口：
   - `https://creator.xiaohongshu.com/publish`
2. 识别当前发布模式（上传视频 / 上传图文 / 写长文）。
3. 如果目标是纯文本笔记，必须切换到“写长文”。

## 2. 编辑前必做检查

1. 确认处于长文编辑器（页面出现“新的创作 / 输入标题 / 粘贴到这里或输入文字”）。
2. 标题优先：先填标题，再填正文。
3. 任意提交动作（“一键排版 / 下一步 / 发布 / 提交”）前，先检查：
   - 标题非空；
   - 正文非空；
   - 页面未出现“请输入标题”等必填错误提示。

## 3. 正文聚焦策略

1. 点击正文区域后，如果画面变化不明显，不要重复同一点点击。
2. 触发焦点确认（插入字符主动探测 + 回滚）：
   - 插入探测字符；
   - 立即回滚（Ctrl+Z 或 Backspace）；
   - 验证内容恢复一致后再正式输入正文。
3. 若焦点确认失败，执行恢复动作：
   - `Esc`；
   - 重新定位编辑区；
   - 再做一次焦点确认。

## 4. 提交流程与防误操作

1. 在长文编辑器中，禁止点击左侧入口“发布笔记”（会跳回入口页并重开流程）。
2. 正确路径：编辑器内“一键排版” -> 预览/下一步 -> 最终发布。
3. 如果误回入口页：
   - 视为流程中断；
   - 重新进入“写长文”并恢复到编辑器状态。

## 5. 动作确认门（防循环）

每次动作后，至少满足其一才允许下一步：

- URL 变化；
- 画面差异超过阈值；
- 目标元素状态变化（按钮消失、新区域出现、文案变化）。

否则进入恢复动作，不重复原动作：

1. `Esc` 关闭弹层；
2. `Ctrl+L` + 输入目标 URL + 回车；
3. 或切换到输入框后 `Ctrl+A` + 粘贴。

## 6. 异常快速定位

1. 连续同点点击无变化：改用键盘导航或滚动，不再重复点击。
2. 截图黑屏：先确认 VM 可交互桌面会话正常，再继续操作。
3. 按钮看不到：先最大化窗口并恢复缩放（如 `win+up`、浏览器缩放 100%）。
